MANUTENÇÃO
Procura áudios no Firebase Storage e tenta vincular automaticamente a consultas antigas sem áudio. Para consultas completadas usa janela de ±90min em torno do fim previsto (createdAt + duração); para consultas pausadas sem duração salva, usa janela larga de ±8h em torno do createdAt.
⚠ CORS no Firebase Storage (necessário para conversão MP3)
Se o botão 🎵 MP3 der "Failed to fetch", o bucket do Storage precisa permitir CORS para fetch. Rode no terminal (precisa do Google Cloud SDK / gsutil): 
echo '[{"origin":["*"],"method":["GET"],"maxAgeSeconds":3600,"responseHeader":["Content-Type"]}]' > cors.json
gsutil cors set cors.json gs://ipagent-frontend.firebasestorage.app
